Local HTML Gadget Authoring Guide

  • You can copy this file (samples/starter-template.html) to any folder and edit it freely.
  • Assets in the same folder or its subfolders (./style.css, ./app.js, images, etc.) can be loaded with relative paths.
  • A control bar appears in the top 28px, so reserving about padding-top: 32px on body makes it easier to use.
  • You can also override styles, such as body { background: transparent !important; }, from "Custom CSS" in the admin screen.
  • External links (https://...) open in the OS default browser rather than inside the gadget.
